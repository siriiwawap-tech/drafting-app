# วิธีติดตั้งระบบองค์กร (สถิติ + คลังโปรเจคกลาง)

1. เปิด Google ชีต (sheets.google.com) สร้างชีตใหม่ ตั้งชื่อ เช่น “แบบก่อสร้าง-องค์กร”
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ในแอปแบบก่อสร้าง กด **⚙️ ตั้งค่าองค์กร → 📋 คัดลอกโค้ดสคริปต์** แล้วลบโค้ดเดิมใน Apps Script วางแทน
4. บรรทัดบน แก้ `'เปลี่ยนรหัสนี้'` เป็นรหัสลับขององค์กร (จำไว้) แล้วกด 💾 บันทึก
5. กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ → ประเภท: เว็บแอป**
6. ตั้ง **ดำเนินการในฐานะ: ฉัน** และ **ผู้มีสิทธิ์เข้าถึง: ทุกคน** → ทำให้ใช้งานได้ → อนุญาตสิทธิ์ (ขั้นสูง → ไปที่โปรเจค → อนุญาต)
7. คัดลอก **URL เว็บแอป** (ลงท้าย `/exec`)
8. กลับมาที่แอป → ⚙️ ตั้งค่าองค์กร → ใส่ชื่อ, วาง URL, ใส่รหัส → 💾 บันทึก → 📡 ทดสอบ
9. กด **🔗 สร้างลิงก์ → 📋 คัดลอก** → ส่งให้ทีมทาง LINE เปิดลิงก์แล้วใส่ชื่อตัวเองครั้งเดียว
10. ดูสถิติ: เปิด Google ชีตเดิม แท็บ **Dashboard / Events / Projects** (ถ้าแก้โค้ดภายหลัง ต้อง Deploy → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่)

ในแอป ปุ่ม “📖 วิธีติดตั้ง (พิมพ์ได้)” กดสองครั้งจะเปิดหน้าพิมพ์ได้
